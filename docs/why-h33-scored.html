1. Mathematical Breakdown of the Distance-Weighted Tversky Index (DTI)

The competition metric is: 

DTI = TP_w / (TP_w + 0.2 · FP_w + 0.8 · FN_w + ε)

Letting $T = \text{TP}_w$, $S = \text{FP}_w$, and $N = T + \text{FN}_w$ (the total kernel-weighted mass of hidden truth): 

DTI = T / (0.2 · (T + S) + 0.8 · N)

Notice that the penalty coefficient for false positives is $\alpha = 0.20$, whereas the penalty for false negatives is $\beta = 0.80$. The metric is 4× more sensitive to missed faults (FN) than to false alarms (FP)!

2. Marginal Bar for Adding Points: Why Denser, Basin-Wide Emissions Win

If we add a candidate dot that lands near hidden truth with probability $p$, the expected change in score is positive if and only if: 

p > 0.2 · DTI

p > 0.2 · (0.2778) = 0.05556 (5.56%)
